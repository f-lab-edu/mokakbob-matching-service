# 🍚 모각밥(Mokakbob) 서비스 전체 기획안

본 문서는 '모르는 사람과 함께 밥 한 끼'를 제안하고 매칭해주는 **모각밥** 서비스의 전체 기능 및 기술 기획을 다룹니다.

## 1. 로그인 및 사용자 관리 (Login & Member)
- **인증 방식**: 
    - 이메일 인증 기반 회원가입 및 로그인 (SMTP 활용)
    - OAuth2 소셜 로그인 (Google, Kakao 등 확장 예정)
    - JWT(JSON Web Token) 기반의 무상태 인증 및 Redis를 활용한 Refresh Token Rotation 적용
- **프로필 관리**:
    - 기본 정보(닉네임, 프로필 이미지 - S3/Local 저장소), 음식 취향(선호 카테고리), 활동 지역 설정
    - 사용자의 신뢰도를 나타내는 '신뢰도 점수' 관리

## 2. 매칭 시스템 (Matching)
- **2.1 매칭 요청**:
    - 사용자가 음식 카테고리, 희망 인원수(2~4명), 현재 위치 정보를 입력하여 매칭을 요청함.
- **2.2 매칭 세부 기획**:
    - **위치 기반 검색**: 도보 15분 내외(약 1km 반경)의 사용자를 우선 매칭.
    - **카테고리 기반 그룹화**: 동일한 음식 취향을 가진 사용자들을 그룹화.
    - **상태 관리**: `PARTICIPATE`(대기) -> `MATCHED`(성사/확정)
    - **자동 처리**: 매칭 성사 즉시 포인트 차감 및 채팅방 생성이 동시에 진행됨 (별도의 수락 단계 없음).
    - **비동기 처리**: Kafka를 활용하여 매칭 성사 시 알림 발송 및 채팅방 생성을 비동기로 처리.

## 3. 매칭 시 채팅 (Chatting)
- **채팅방 생성**: 매칭이 성사(`MATCHED`)되면 즉시 자동으로 채팅방 생성.
- **실시간 통신**: WebSocket 및 STOMP 프로토콜 사용.
- **확장성**: Redis Pub/Sub을 활용하여 여러 서버 인스턴스 간 메시지 전파.
- **이력 관리**: 채팅 내역은 DB에 저장하며, 최근 메시지는 고성능 조회를 위해 Redis에 캐싱.

## 4. 포인트 및 결제 (Point & Payment)
- **포인트 충전**: 포트원(Portone, 구 아임포트)을 통한 신용카드, 간편 결제 등 지원.
- **포인트 사용**: 매칭 성사 시 자동 차감.
- **거래 내역**: 충전, 매칭 사용, 취소 환불 등 모든 트랜잭션의 상세 로그 기록.

## 5. 후기 및 신뢰도 시스템 (Review & Trust)
- **후기 작성**: 매칭 종료 후 참여자 상호 간 매너 및 만족도 평가.
- **신뢰도 계산**: 
    - 긍정/부정 후기 데이터를 기반으로 사용자 신뢰 점수 실시간/배치 업데이트.
    - 노쇼(No-show) 발생 시 강력한 점수 감점 및 서비스 이용 제한.
- **우선순위**: 신뢰 점수가 높은 사용자에게 매칭 우선권 부여 등 혜택 제공.
